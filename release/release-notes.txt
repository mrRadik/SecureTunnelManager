RDP — КОМПЬЮТЕРЫ ЧЕРЕЗ JUMP HOST
═══════════════════════════════════════

• Отдельная страница RDP с сеткой компьютеров (как Radmin)
• Двойной клик поднимает SSH через jump host и открывает встроенный Remote Desktop (mstsc)
• Автологин: username/password в профиле → временный .rdp (password 51:b) + cmdkey
• Локальный порт 0 — свободный порт на каждую сессию; туннель гасится после закрытия Remote Desktop
• Страница Туннели и RDP разделены: произвольные пробросы и удалённые ПК отдельно

ИНТЕРФЕЙС — ТЕМЫ
═══════════════════════════════════════

• Три режима оформления в настройках: светлая, тёмная и «Как в системе»
• Режим «Как в системе» подстраивается под тему Windows (Параметры → Персонализация → Цвета)
• Переключение темы без перезапуска приложения — все экраны обновляются сразу
• Светлая тема в стиле Fluent Design — светлый фон, белые карточки, читаемые контрасты
• Выбор темы сохраняется между сеансами
• Локализация подписей темы (EN/RU)
