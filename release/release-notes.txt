ОБНОВЛЕНИЯ
═══════════════════════════════════════

• Полный редизайн интерфейса — единый компактный стиль всех окон приложения
• Обновлены экраны Tunnels, RDP, Settings, Share, Unlock Vault и мастера создания соединений
• Улучшены layout, типографика и визуальная иерархия; функциональность без изменений
• Открытие SSH-терминала из контекстного меню туннеля — команда ssh собирается автоматически (Windows Terminal или PowerShell)
• Если туннель запущен и пробрасывает SSH (порт 22), терминал подключается к конечному серверу через локальный порт — пароль jump host не нужен
• Если туннель остановлен, подключение идёт через jump host (-J); пароли вводятся в терминале вручную
